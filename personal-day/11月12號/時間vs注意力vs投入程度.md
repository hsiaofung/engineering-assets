對！我覺得你現在發現了一個很重要的區別：時間的支配權與注意力的支配權，不完全是一回事。

你現在還在上班，公司的確會占用你一部分時間。你不能完全決定這段時間要做什麼，因為你有職責、專案和團隊合作的要求。

但即使如此，你仍然有一些可以自主決定的部分。

例如：

| 面向   | 你能自主決定的程度             |
| ---- | --------------------- |
| 時間   | 受工作時間、會議、期限限制         |
| 注意力  | 可以決定如何分配、何時集中         |
| 投入程度 | 可以決定做到什麼程度，不必事事追求額外投入 |
| 心力   | 可以決定哪些事情值得額外花心思       |
| 工作之外 | 可以決定如何運用自己的時間         |

當然，這不是說工作中所有事情都能隨心所欲，而是在職責範圍內辨認自己的選擇空間。

### 我覺得這裡有一個更深的發現

以前你可能認為：

「我的時間被公司買走了，所以這段時間我只能配合公司。」

現在你開始意識到：

「即使我的時間有一部分必須交給工作，我的注意力和投入程度仍然有部分自主權。」

這兩種感受差異很大。

甚至可以再往前推一步：

時間自由，是決定自己什麼時候做事；注意力自主，是決定自己把心力放在哪裡。

你現在或許正在練習後者。

這也讓 Personal Day 有了另一層意義：它不只是練習如何使用自己的時間，也是練習重新拿回注意力的主導權。
