我覺得可以先把「內在狀態」分成幾個部分。不過先釐清一件事：

內在狀態不是全部都能直接控制，但有些可以透過自己的選擇與練習，逐漸取得主導權。

以你目前的工作情境為例：

| 內在狀態 | 你可以自主的部分             |
| ---- | -------------------- |
| 注意力  | 決定把注意力放在哪件事情上        |
| 投入程度 | 決定額外投入多少時間與心力        |
| 專注程度 | 決定何時深入思考、何時暫停        |
| 情緒反應 | 不一定能控制情緒出現，但可以選擇如何回應 |
| 思考方向 | 決定要繼續鑽研問題，還是暫時放下     |
| 價值判斷 | 決定什麼事情對自己真正重要        |
| 期待   | 可以調整自己對結果的期待         |
| 態度   | 決定用什麼態度面對工作與他人       |

### 但我認為有三個層次值得區分

第一層：可以直接選擇的

例如，我現在要把注意力放在 coding，還是先休息一下。

第二層：可以影響，但不能完全控制的

例如，焦慮、罪惡感、挫折感。

你不能命令自己「不要焦慮」，但可以決定不因為焦慮就立刻回去工作。

第三層：不能直接控制的

例如，別人怎麼評價你、專案最後的結果、主管是否認可你的表現。

你可以影響它們，但不能保證結果。

### 我想把這件事連回今天的 Personal Day

你今天發現，雖然公司掌握了你部分工作時間，但你仍然可以決定自己的注意力和投入程度。

我覺得這裡有一個很重要的延伸：

自主性不一定是控制外在環境，而是逐漸取得對自己內在反應的主導權。

甚至可以說：

- 我不能決定今天有多少工作。
- 但我可以決定如何分配注意力。
- 我不能決定主管如何評價我。
- 但我可以決定自己如何看待這個評價。
- 我不能決定專案是否順利。
- 但我可以決定投入多少心力，以及如何面對結果。

這和我們之前談的「應無所住，而生其心」也很接近。

不是對外在事情無所謂，而是不要讓外在事情完全決定自己的內在狀態。
