# Design Token
- 你對 Design Token 的興趣，可能不是因為公司現在「交代你研究 Design Token」，而是你在工作中碰到 styling、component、design system 這些問題後，自己產生了延伸的好奇心。

# 工作經驗會不會成為你退休後仍然會主動探索的知識來源？
- 如果答案是會，那你的未來未必是：工作 → 退休 → 完全離開技術
- 可能反而是：公司工作 → 自主探索 → 個人作品／研究 → 創業或其他可能
- 你可能真正想離開的是：被公司決定「今天要研究什麼」。 而不是：研究技術這件事情本身。
