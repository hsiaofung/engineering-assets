# 但是執著要多大才算是執著變成偏執呢? 有時候我們不也說執著是好事? 因為執著才會成功?

你提出了一個很重要的問題：執著不一定是壞事，甚至我們常常把執著當成成功的必要條件。

例如：

- 他對音樂很執著，所以持續練習，最後成為音樂家。
- 他對研究很執著，所以花十年鑽研，終於有所突破。
- 他對自己的理想很執著，即使遇到挫折也不放棄。

這些情況，我們通常會稱讚他有毅力、有信念，而不是說他偏執。

所以，我認為需要把三個概念分開。

### 1. 堅持：我想要，所以我持續努力

我有一個目標，即使過程辛苦，也願意投入時間。

但我知道：

- 方法可以調整。
- 目標可以重新評估。
- 結果不一定如我所願。

這種堅持通常是正面的。

### 2. 執著：我開始不能放下這個結果

例如，我想升職，所以努力工作。

但幾年過去，我始終沒有升職，開始覺得：

- 沒有升職，就代表我不夠好。
- 別人升職，我就覺得自己輸了。
- 即使這份工作已經不適合我，我也不能離開，因為我一定要得到這個職位。

這時候，目標已經不只是目標，而是逐漸變成一種心理上的依附。

### 3. 偏執：我只接受自己的想法，難以容納其他可能

例如，我認定自己一定要升上主管。

即使客觀條件已經改變，別人提出合理建議，我也不願意考慮；甚至為了升職，不惜犧牲健康、家庭或其他重要價值。

這就比一般所說的執著更接近偏執。

### 那麼，執著要到什麼程度才算有問題？

我覺得不能單純用「投入多少時間」或「想要得多強烈」來判斷。

更值得觀察的是：

當現實不符合我的意願時，我還有沒有選擇的空間？

例如：

| 情況                | 心理狀態         |
| ----------------- | ------------ |
| 我很想成功，所以持續努力      | 堅持           |
| 我很想成功，失敗時會難過，但能調整 | 有強烈意願，但不一定執著 |
| 我一定要成功，否則無法接受自己   | 執著           |
| 我只認定一條路，拒絕所有其他可能  | 可能走向偏執       |

不過，這只是日常語言上的區分，不是佛教對「執著」與「偏執」的正式分級。

回到我們前面談的《金剛經》：

「應無所住，而生其心。」

它並不是叫人不要有目標、不要努力，也不是叫人對任何事情都無所謂。

而是：

你可以全心投入一件事，但不要把自己的一生，綁定在這件事必須得到某個結果上。

我覺得這裡有一個很有意思的區別：

堅持，是我願意為目標付出；執著，是我開始要求現實必須按照我的意願發生。
