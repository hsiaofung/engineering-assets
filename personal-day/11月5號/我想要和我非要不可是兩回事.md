# 既然是自己的意願? 又怎麼會被自己的意願束縛呢? 因為這是你想做的啊。

這個疑問很好。乍看之下確實矛盾：既然是自己的意願，為什麼還會被自己的意願束縛？

關鍵在於：「我想要」和「我非要不可」是兩回事。

我們用升遷來舉例。

### 第一種：有意願，但不執著

我想升主管，因為我喜歡帶領團隊，也希望薪水更好。

所以我努力爭取。

但如果最後沒有升遷，我會失望，卻也能接受。我可以繼續做工程師，也可以尋找其他機會。

我仍然有這個意願，但沒有把人生綁在這個結果上。

### 第二種：有意願，卻被意願綁住

我想升主管。

但慢慢變成：

- 沒升主管，就覺得自己沒有價值。
- 同事升得比我快，就感到不甘心。
- 即使已經不喜歡管理工作，也不願意放棄主管頭銜。
- 為了升遷，不斷犧牲自己真正重視的生活。

原本是我想要升遷，後來卻變成我不能不升遷。

這就是意願變成執著。

### 所以兩者的差別是：

| 有意願      | 被意願束縛    |
| -------- | -------- |
| 我想要      | 我非要不可    |
| 可以努力     | 必須成功     |
| 可以接受其他選擇 | 無法接受其他結果 |
| 意願由我選擇   | 我被意願牽著走  |

我覺得可以用一句話概括：

意願讓你有方向，執著讓你失去其他方向。

所以《金剛經》的「應無所住，而生其心」，並不是叫你不要有自己的意願。

而是你可以很清楚地知道自己想要什麼，也可以全心投入，但不必因為沒有得到，就認為自己的人生失去了意義。
