我先給一個明確的定義：

執著，是對某個人、事、物、想法或結果產生過度的心理依附，以至於難以接受它改變、失去，或不如自己的期待。

這裡有幾個重要特徵。

### 1. 執著不只是想要，而是不能接受沒有得到

例如：

- 想升遷：這是意願。
- 沒升遷會失望：這是正常情緒。
- 沒升遷就認為自己沒有價值：這可能是執著。

### 2. 執著是把某件事變成必要條件

例如：

- 我必須有錢，才能安心。
- 我必須得到別人肯定，才能認同自己。
- 我必須按照計畫退休，人生才算成功。
- 我必須得到某個結果，才願意接受現在的生活。

原本只是想追求的東西，逐漸變成自己認為不可缺少的東西。

### 3. 執著會限制其他可能性

例如你想跳槽：

- 因為想追求更好的工作，所以離開。
- 因為不能忍受現在的主管，所以非離開不可。
- 即使新工作更差，也覺得一定要離開，否則就是認輸。

後兩者可能反映出心理上的束縛。

### 我想把它整理成一個簡單的區別

| 心理狀態 | 內在想法            |
| ---- | --------------- |
| 意願   | 我想要這件事          |
| 期待   | 我希望它發生          |
| 失望   | 結果不如預期，我感到難過    |
| 執著   | 它非得發生不可，否則我無法接受 |

這裡要注意：執著不一定等於強烈的情緒，也不一定是外在行為。有人表面上很平靜，內心卻無法放下某個結果。

### 回到《金剛經》

「應無所住，而生其心。」

我認為可以先這樣理解：

- 生其心：允許自己有願望、有追求、有行動。
- 應無所住：不要把願望變成非實現不可的心理依附。

你可以很想得到一件事，但不必因為得不到，就失去好好生活的能力。

這是「意願」與「執著」之間很重要的界線。
