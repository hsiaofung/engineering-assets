# 開發順序: 
```json
1. Route Structure
        ↓
2. Ancestor API Adapter
        ↓
3. Route Builder
        ↓
4. Resource Resolve Guard
        ↓
5. Navigation Update
        ↓
6. Tests
```
# 原因：
- Route 要先有骨架       
- API 要先有資料來源           
- Builder 定義 canonical URL            
- Guard 才能組合             
- 最後才改各入口
