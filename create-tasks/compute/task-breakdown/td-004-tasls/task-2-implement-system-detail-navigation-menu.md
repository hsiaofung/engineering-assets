# Task 2：Implement System Detail Navigation Menu✅

## Purpose

實作 Appliance Level 的導覽結構，使使用者可以在各功能頁之間切換。

## Scope

- 建立 Navigation Menu
- 支援群組節點 Overview
- 支援 Active State
- 支援 Router 導航
- 支援 Expand / Collapse

## Acceptance Criteria

- 點擊 Navigation 可切換至正確 Route。
- Active Menu 與目前 URL 保持同步。
- Group Navigation 行為符合 UX 設計。
- Browser Back / Forward 時 Navigation 狀態正確。
