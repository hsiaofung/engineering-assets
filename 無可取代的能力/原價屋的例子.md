我們可以這樣看：

### **第一階段：創造新的選擇**

以前消費者買電腦，主要選擇是：

- 購買 ASUS、Acer、HP 等品牌電腦。
- 規格、配置與價格主要由品牌廠商決定。

後來 DIY 自組電腦逐漸普及，消費者有了另一種選擇：

- 自己挑選 CPU、主機板、記憶體、顯示卡。
- 自己決定電腦規格。
- 依照預算與用途組合零件。

這改變了消費者購買電腦的方式。

### **第二階段：建立無可取代的價值**

但自組電腦的選擇出現，不代表消費者自然就會找原價屋。

原價屋必須逐步建立自己的價值：

| 價值       | 消費者得到什麼   |
| -------- | --------- |
| 零組件品項豐富  | 可以自由搭配    |
| 價格透明     | 容易比較與控制預算 |
| 組裝服務     | 不必自己動手    |
| 零件相容性建議  | 降低選購錯誤    |
| 品牌知名度與信任 | 買得比較放心    |

這些價值逐漸累積，讓消費者想到 DIY 電腦時，可能就會想到原價屋。

當然，這不代表原價屋是唯一選擇，也不是說它單獨創造了 DIY 市場；DIY 電腦是整個產業與消費文化共同發展的結果。

### **這個例子讓我們看到一個重要的商業邏輯**

**從新選擇到市場地位**

1. **市場原有選擇**

   買品牌電腦。
2. **創造新的選擇**

   DIY 自組電腦。
3. **提供新的價值**

   零件選擇、價格透明、組裝與諮詢。
4. **累積競爭優勢**

   品牌、信任、供應鏈、服務與客戶經驗。
5. **建立市場地位**

   成為消費者想到 DIY 電腦時的重要選擇。

我想再推進一個觀念：

**創造新選擇的人，不一定就是最後建立市場地位的人。**

例如，DIY 電腦不是原價屋發明的，但原價屋可以透過更好的商品組合、服務與經營方式，在這個市場中建立自己的位置。

所以商人的本事，可能還包含一項：

**不只是創造新的可能性，還要懂得如何在這個可能性所形成的新市場中，建立自己的位置。**

這和呂不韋的故事又有一點呼應：異人登基是一個可能性的實現；呂不韋接著建立自己的政治地位。兩個階段的任務不同。
