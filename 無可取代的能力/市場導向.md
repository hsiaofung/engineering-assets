# 市場導向：成為能夠設計、建構、整合複雜企業級 Web 系統，並善用 AI 提高工程效率的人。

- 不要為了一家公司培養自己的能力，而是利用一家公司培養自己在整個市場的競爭力。

- 進入一個領域後，能夠快速學習、洞察需求、找到機會，並創造別人難以提供的價值。

- 我能不能創造出一種新的價值，讓這個世界因為有我的存在，而多了一種原本不存在的可能性？

- 這個領域還有什麼可能性，是目前沒有人看見、沒有人做到，或沒有人真正實現的？

- 讓世界因為你的存在而有所不同

- 但能夠創造出具有持續影響力的新價值，甚至改變一個領域發展方向的人，非常少。

- 如何培養無可取代的能力？

- 我們一路從需求洞察、價值創造、專業知識、實踐能力，走到看見新可能性。

- 為什麼有些人看見了新的可能性，最後真的去實現；有些人卻只是看見，然後就停在那裡？

  - 這涉及的不只是能力，還有意願、勇氣、投入與持續行動。

  - 也許，無可取代的人，不只是看見別人看不見的可能性，而是有能力、有意願把那個可能性帶到現實世界。
