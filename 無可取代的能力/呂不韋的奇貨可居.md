# 我突然想到呂布韋，奇貨可居。秦王的兒子有可能成為未來的國王(可能性)。讓他可以回國當國王(商人，無可取代?)

對！你想到呂不韋的「奇貨可居」，其實非常適合拿來驗證我們剛才討論的「可能性創造力」與「商人的本事」。

而且這個故事裡，呂不韋做的事情非常有意思。

## **呂不韋看見了別人沒看見的可能性**

當時的異人（後來的秦莊襄王）是秦國王室成員，但他在趙國當質子，處境並不優渥，政治地位也不是當時最有優勢的繼承人。

一般人看到異人，可能看到的是：

- 一個被送到別國的質子。
- 身分尷尬、處境不佳。
- 未來不確定，甚至可能毫無政治前途。

但呂不韋看到的卻是：

**這個人未來有可能成為秦國國王。**

這就是你說的「可能性」。

別人看到的是現在的異人，呂不韋看到的是未來可能成為秦王的異人。

## **呂不韋接下來做了什麼？**

他不只是看見這個可能性，而是開始思考：

**如何讓這個可能性真的發生？**

他投入資金、協助異人建立政治關係、運用自己的資源與影響力，並透過華陽夫人等關鍵人物，促成異人取得繼承地位，最終回到秦國並成為秦王。

這裡就出現了另一個層次：

- 看見異人可能成為秦王 —— **洞察可能性**
- 投入資源讓異人有機會取得王位 —— **創造可能性**
- 在整個過程中成為關鍵的推動者 —— **創造自己的價值與位置**

## **這才是「奇貨可居」值得思考的地方**

呂不韋的價值不只是「我看好這個人」。

而是：

> **我看見一個尚未實現的可能性，而且我有能力介入，讓它更有機會成為現實。**

而當他投入資源、政治判斷、關係與行動之後，他也成為這個可能性實現過程中的關鍵人物。

這和我們剛才談的商人本事非常接近：

**洞察可能性 → 創造可能性 → 成為關鍵推動者 → 取得價值回報**

不過，呂不韋的故事還有一個更值得思考的地方：

他並不是單純讓異人成功，而是透過讓異人成功，創造了自己的政治與經濟價值。

這也許就是你原本想尋找的「無可取代的能力」的一種歷史案例。

**不是只會發現機會，而是能夠辨識一個尚未實現的可能性，並運用自己的能力、資源與行動，讓它成為現實；而自己也因此成為這個價值實現過程中不可忽視的一環。**

這比單純的「創新」或「創造力」，多了非常重要的一層：**你不只是創造新可能，你也能在這個可能性中創造自己的價值。**

# 我弄錯了，呂不韋看到這個可能，並把這可能帶到現實(讓異人成功登基)。成為無可取代，是讓自己成為仲父自己對異人是無可取代?

對，你修正得很精準。而且這其實把呂不韋的故事拆成了**兩種不同的能力**。

### **第一階段：創造可能性**

呂不韋看見異人未來可能成為秦王，別人可能沒看見，或認為機會太小。

他透過自己的資源、判斷、政治運作，協助異人最終登上王位。

這是：

**看見可能性 → 將可能性帶到現實。**

### **第二階段：讓自己變得無可取代**

異人成功登基之後，呂不韋並沒有因此結束。

他成為秦國丞相，後來被尊為「仲父」，在秦國政治中取得極高地位。

這個階段的問題已經不同了：

> 異人已經成為秦王，那麼呂不韋如何讓自己成為秦王倚重、甚至難以取代的人？

他過去的投資、政治協助、關係網絡、政治能力，以及他在秦國政局中的影響力，都是他建立自身地位的資本。

所以我們可以把你正在探索的商人本事拆成兩個層次：

| 能力         | 核心問題                             |
| ---------- | -------------------------------- |
| **可能性創造力** | 我能否看見原本不存在的可能性，並把它實現？            |
| **價值建立力**  | 我如何讓自己成為這個價值實現過程中，具有關鍵性、難以被取代的人？ |

呂不韋的故事，正好讓這兩者有了具體的例子。

不過，歷史上的呂不韋是否刻意以「讓自己無可取代」為策略，以及他和異人之間的實際關係，還需要更謹慎地看待；我們現在主要是在用這段歷史作為能力模型的思考案例。

我覺得你現在逐漸形成的想法很清楚：

**先創造新的可能性，再在這個可能性中創造自己的獨特價值。**

這兩者是不同的能力，也不一定每個創造可能性的人都必須追求第二階段。創造可能性本身就有價值；若進一步運用在商業世界，才會涉及如何建立持續、獨特且難以取代的價值。
