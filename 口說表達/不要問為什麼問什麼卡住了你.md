# 所以不要問為什麼，問什麼卡住了你? 你遇到了什麼困難?

對！我認為你找到了一個很實用的溝通轉換方式。

**把「追究原因」轉換成「了解障礙」，可以降低對方的防衛心理。**

例如：

| 容易讓人感到被質疑 | 比較有同理心的問法         |
| --------- | ----------------- |
| 你為什麼還沒完成？ | 目前是什麼卡住了？         |
| 你為什麼沒有通知？ | 當時遇到了什麼困難？        |
| 你為什麼沒有處理？ | 有什麼因素讓你無法繼續處理？    |
| 你為什麼沒有想到？ | 這個過程中有沒有遇到什麼資訊落差？ |

不過，我想補充一個重要觀念：

## **不問「為什麼」，不代表不釐清責任**

我會把溝通分成三個階段：

1. **第一階段：理解**

   「目前是什麼卡住了？」

   先了解對方的處境，不急著下判斷。
2. **第二階段：釐清**

   「哪些部分是我們可以控制的？哪些部分需要其他人協助？」

   區分可控與不可控因素。
3. **第三階段：承擔**

   「接下來我們怎麼處理？誰負責哪個部分？」

   回到責任、行動與結果。

## **但有一個細節值得注意**

其實「為什麼」本身不是錯誤的問題。

例如：

- 「你為什麼沒完成？」容易被理解為責備。
- 「你認為這次延遲的主要原因是什麼？」則可能是中性的問題。

真正影響對方反應的，是提問背後傳遞的訊息：你是在尋找問題，還是在尋找犯錯的人？

我會用一句話總結這套溝通方式：

**先理解困難，再釐清責任，最後共同解決問題。**

這樣既不需要犧牲同理心，也不需要放棄問責制。
