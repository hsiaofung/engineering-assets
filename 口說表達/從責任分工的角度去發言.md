# 我發現從責任分工的角度去發言，比誰做的角度去發言，來得比較好?

我覺得你發現了一個很重要的溝通技巧，而且它比單純學習如何提問更深一層。

**從「責任分工」出發，而不是從「誰來做」出發，可以降低人際上的對立。**

兩者看起來很接近，但背後的思考方式不同。

## **一、比較一下兩種說法**

假設專案遇到一個問題，需要 FE 和 BE 合作。

| 從誰做出發     | 從責任分工出發                  |
| --------- | ------------------------ |
| 這個你處理一下   | 這部分應該由哪一方負責？             |
| 為什麼你不做？   | 這項工作目前的責任歸屬是什麼？          |
| 這不是你的工作嗎？ | 我們原本是怎麼分工的？              |
| 你去問 BE    | 這個問題需要 BE 提供什麼資訊？        |
| 這個我不負責    | 這部分不在 FE 的職責範圍，需要由 BE 確認 |

你會發現：

第一種容易讓人感覺是在分配工作、推卸工作，甚至追究誰沒有做事。

第二種則是在確認工作流程、職責邊界和合作方式。

## **二、為什麼責任分工比較好？**

我認為有三個原因。

**1. 不容易產生人身對立**

討論的是工作，而不是某個人有沒有做好。

**2. 責任歸屬比較清楚**

不會因為某個人比較熱心、比較有能力，就讓所有事情都落到他身上。

**3. 更容易建立合作**

每個人知道自己的責任，也知道需要別人提供什麼協助。

## **三、這讓我想到一個更重要的區別**

以人為中心

**誰應該做這件事？**

容易變成工作分配與責任歸咎。

以事情為中心

**這件事需要哪些工作？各自的責任是什麼？**

比較容易形成清楚的分工與合作。

不過，我想補充：責任分工不是為了讓每個人只做自己的事。

如果遇到跨部門問題，可能需要有人協調、有人提供資訊、有人執行。

即使某件事不屬於你的主要職責，你仍然可以選擇協助，但不代表責任歸屬因此改變。

## **四、我認為你可以把這個觀念延伸成一個原則**

**不要急著問誰來做，先釐清事情需要什麼，以及每個人應該承擔什麼。**

這其實也回到我們最初討論的高度同理心與高度問責制：

- 同理心：理解每個人的處境與限制。
- 問責制：確認每個人的責任與承諾。
- 責任分工：讓彼此知道如何合作，而不是互相推卸。

我覺得這是一種很值得培養的職場溝通能力。尤其在 FE、BE、UX、PM 多方合作的環境中，**把問題從「人與人之間的責任爭論」，轉換成「工作與職責之間的協調」，往往能讓討論更有效率。**
