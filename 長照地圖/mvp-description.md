## 問題

你的爸爸、媽媽年紀大了，可能有失智症，需要人照顧。你站在客廳裡，面前是失智需要照顧的父親或母親，卻不知道該怎麼辦。你不知道家裡附近有哪些機構、資源可以幫助你?

## 解決方案

一個簡單的網頁應用：使用者輸入家庭地址，系統立刻根據匹配程度排序，推薦最符合的長照機構，優先顯示最近的長照機構並顯示評價和聯絡方式。

## 核心 MVP 流程

1. 使用者進入乾淨的首頁，看到明顯的地址輸入欄
2. 使用者加入地址
3. 使用者按下「尋找長照機構」
4. 應用程式回傳依地址距離最近排序的長照機構卡片列表
5. 使用者點擊卡片，查看長照機構的評價和聯絡方式

## 每家長照機構需顯示的重點資訊

- 家照機構名稱與圖片
- 服務的項目
- 與家的距離有多近
- 沒有提供的服務會被特別標示
- 詳細頁面需顯示評價及聯絡方式

## MVP 範圍

- 不需要使用者帳號或登入
- 不提供收藏／儲存功能（保持無狀態）
- 長照機構資料使用靜態模擬資料集（約 30–50 道）
- 單一頁面體驗，導航盡量簡化
- 支援手機並具備響應式設計

## 不在範圍內

- 使用者帳號、登入、已儲存的長照機構
- 長照機構限制篩選（可於 MVP 後再加入）
- 外部 API 整合（先以模擬資料開始，之後再替換）
