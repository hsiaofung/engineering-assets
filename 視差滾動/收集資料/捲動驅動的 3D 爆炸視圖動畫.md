## 我建議你先理解一個核心技術概念

其實這類動畫的核心並不複雜：

Scroll Position → Animation Progress → 3D Object Position

也就是：

使用者捲動網頁

取得 Scroll Progress（0～1）

計算每個零件的位置

Three.js 更新 3D 畫面

例如每個零件原本都有自己的位置 `originalPosition`，拆解後有自己的 `explodedPosition`。

動畫過程就是在兩個位置之間插值：

```
part.position.lerpVectors(
  originalPosition,
  explodedPosition,
  scrollProgress
);
```

這是整個效果最值得先理解的地方。

## 建議你的研究順序

1. 先學會 GSAP ScrollTrigger，理解如何將捲動進度轉換成動畫進度。
2. 再學 Three.js，理解 Scene、Camera、Mesh、Geometry。
3. 載入一個 `.glb` 3D 模型。
4. 將模型拆成多個零件。
5. 讓 ScrollTrigger 控制每個零件的位置。

這樣你就能從一個簡單的網頁捲動動畫，逐步做到完整的 3D 產品拆解展示。
