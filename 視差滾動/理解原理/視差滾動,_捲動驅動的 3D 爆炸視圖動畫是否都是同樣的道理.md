# 視差滾動, 捲動驅動的 3D 爆炸視圖動畫是否都是同樣的道理? Scroll Position -> Animation Progress -> 3D Object Position (前、中、後圖層)

對！你的理解已經抓到核心了。

視差滾動（Parallax Scrolling）和捲動驅動的 3D 爆炸視圖動畫，本質上都是利用 Scroll Position 控制畫面元素的變化。

兩者的基本運作邏輯相同，但控制的對象與動畫複雜度不同。

我們可以把它們放在同一個架構下理解。

## 1. 共同的核心原理

兩者都可以用這個流程表示：

Scroll Position

使用者目前的捲動位置

Animation Progress

將捲動位置轉換成 0～1 的動畫進度

Update Visual Properties

依照動畫進度更新畫面元素

這裡有個重要觀念：

最後一步不一定是更新 Position，也可以更新：

- Position：位置
- Rotation：旋轉角度
- Scale：大小
- Opacity：透明度
- Color：顏色
- Camera：攝影機位置與角度

所以更通用的表達方式是：

Scroll Position → Animation Progress → Visual Properties

## 3. 用程式碼理解兩者的關係

其實兩者可以使用相同的動畫概念。

視差滾動：

```
const progress = getScrollProgress();

foreground.position.y = progress * 100;
middle.position.y = progress * 50;
background.position.y = progress * 20;
```

3D 爆炸視圖：

```
const progress = getScrollProgress();

parts.forEach((part) => {
  part.position.lerpVectors(
    part.originalPosition,
    part.explodedPosition,
    progress
  );
});
```

兩者的差異主要在於：

- 第一個是多個圖層依不同速度移動。
- 第二個是多個 3D 物件依照各自設定的目標位置移動。

## 4. 我想幫你建立一個更高層次的理解

你可以把這些效果歸納成一個共同的技術架構：

## Scroll-driven Animation

捲動驅動動畫：以捲動進度作為動畫控制來源。

Input

Scroll Position → Animation Progress

Animation Mapping

將進度映射到不同物件的動畫屬性

2D / DOM

- Parallax
- Fade In
- Slide In
- Scale

3D / WebGL

- Exploded View
- Rotation
- Camera Movement
- Object Assembly

所以，你現在不需要把視差滾動和 3D 爆炸視圖當成兩種完全不同的技術來學習。

你應該先掌握共同的核心：如何將 Scroll Progress 映射到動畫屬性。

接著再學習 DOM/CSS 動畫和 Three.js 3D 動畫的不同實作方式。

這樣學習會更有系統，也比較容易舉一反三。
