# 什麼是視差滾動(parallax scrolling)？
視差滾動是一種技術，當滾動頁面時，背景影像的移動速度比前景內容慢，從而產生深度錯覺。

它的核心由三個部分組成：

多個視覺圖層相互堆疊
每層移動的速度都不同。
移動與滾動位置相關
運用得當，它能營造出景深效果；運用不當，則可能導致暈動症或影響觀看體驗。關鍵在於流暢性和微妙性。

# 為什麼要使用視差滾動？
視差滾動效果讓網站令人難忘。在一片扁平化的頁面中，微妙的動態效果能夠創造深度，並激發情感共鳴。

用途：

- 需要給人留下深刻第一印象的精彩片段
- 引導使用者進行敘事的敘事頁面
- 展示視覺設計技能的作品集網站
- 現代瀏覽器在合成執行緒上運行變換，因此即使在行動裝置上，視差效果也很流暢。如果運用得當，它是你能添加的最流暢的效果之一。

跳過以下情況：

- 您的網站內容繁多，用戶需要快速瀏覽。
- 你無法妥善支持減少運動偏好
- 你時間很緊
- 最好的視差效果是微妙的。如果使用者能感受到平滑感，但卻無法解釋原因，那就表示你做得非常出色。
