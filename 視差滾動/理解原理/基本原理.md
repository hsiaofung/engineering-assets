# 所以是同一套的方法，只是視覺特性換成camera 的位置，對吧?

完全正確！你的理解是對的。

核心方法是同一套，差別在於 Scroll Progress 最後控制的視覺屬性不同。

我們可以統一成這個公式：

\\[ Scroll\ Position \rightarrow Progress \rightarrow Visual\ Properties \\]

| 效果       | 被控制的對象  | 控制的屬性                      |
| -------- | ------- | -------------------------- |
| 視差滾動     | 前、中、後圖層 | Layer Position             |
| 3D 爆炸視圖  | 產品零件    | Object Position / Rotation |
| 宇宙到地面的穿越 | Camera  | Camera Position / Rotation |

例如：

- 視差滾動：Progress 50%，背景移動 20px。
- 爆炸視圖：Progress 50%，手錶零件分離一半。
- Camera Fly-through：Progress 50%，攝影機抵達雲層附近。

還有一個值得注意的觀念：

Scroll Progress 不一定只能控制一個物件，也可以同時控制多個物件的多種屬性。

例如宇宙穿越效果：

- Camera 往地球移動。
- 雲層逐漸放大。
- 星星逐漸淡出。
- 地球逐漸佔滿畫面。

全部都可以由同一個 Scroll Progress 驅動。

所以我會建議你把研究主題定為：

Scroll-driven Animation（捲動驅動動畫）

而 Parallax、Exploded View、Camera Fly-through 都是這個概念下不同的應用方式。

這樣你學到的是一套可以反覆應用的底層思維，而不是三種獨立的動畫技巧。
