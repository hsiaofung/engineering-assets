## 表單無障礙設計（Accessibility for Forms）重點整理

### 為什麼表單無障礙很重要？

* 表單是網站最重要的互動元件之一（登入、註冊、購物、聯絡、搜尋等）。
* 好的表單不只要**好看**，更要：

  * 易於理解
  * 易於操作
  * 對所有人（包含身心障礙者）都能使用

> **目標：讓所有使用者都能順利完成表單，而不是只有一般使用者。**

---

## 無障礙（Accessibility） vs 可用性（Usability）

| 可用性 (Usability) | 無障礙 (Accessibility) |
| --------------- | ------------------- |
| 使用起來是否容易        | 是否有能力使用             |
| 重視操作效率          | 重視所有人都能存取           |
| 所有人皆適用          | 特別考量身心障礙使用者         |

兩者並不衝突，而是互補。

---

# 設計表單前應思考

建立表單時，可以先問自己：

* 視障者能完成嗎？
* 使用者知道每個欄位要填什麼嗎？
* 表單容易理解嗎？
* 可以完全使用鍵盤完成嗎？

---

# 不同使用者的需求

## 1. 視障使用者

需要：

* Label（標籤）
* 鍵盤操作
* 螢幕閱讀器支援
* 足夠色彩對比

如果沒有 Label：

* Screen Reader 會不知道此欄位用途
* 有些欄位甚至直接被跳過

---

## 2. 認知障礙使用者

改善方式：

* 清楚版面
* 明確指示
* 清楚回饋
* 說明文字

不要讓使用者猜測：

> 這欄到底要填什麼？

---

## 3. 行動不便（靈巧度有限）

改善方式：

* 大的可點擊區域
* Label 可點擊
* 容易選取控制項

不要只有小小的 Checkbox 可以點。

---

## 4. 使用語音控制的人

如果 Label 完整：

使用者可以直接說：

> Click Email

或

> Focus Password

語音控制才能正常運作。

---

# 表單無障礙最佳實務

## 1. 支援鍵盤操作（Keyboard Accessible）

使用者應能：

* Tab
* Shift + Tab
* Enter
* Space

完成整份表單。

不能只能靠滑鼠。

---

## 2. 使用足夠色彩對比

讓使用者容易辨識：

* Label
* Input
* Required
* Error

可利用色彩對比工具檢查是否符合標準（例如 WCAG）。

---

## 3. 每個欄位都要有 Label

例如：

✅

```
Email
[____________]
```

而不是

```
[Email]
```

(Label 不能只靠 Placeholder)

原因：

* Screen Reader 可朗讀
* Voice Control 可辨識
* 容易理解

---

## 4. Label 要與 Input 關聯

例如：

```html
<label for="email">Email</label>
<input id="email">
```

不要只放一段文字：

```
Email

<input>
```

否則輔助工具不知道兩者有關聯。

---

## 5. 欄位分組要有意義

例如：

```
姓名

地址

付款資訊

聯絡資訊
```

應該清楚分群。

---

## 6. 錯誤訊息要清楚

錯誤應：

* 清楚
* 簡潔
* 發生時立即出現
* 出現在錯誤欄位附近

例如：

❌

```
Something went wrong.
```

✅

```
Email 格式不正確
```

---

## 7. 不要依賴 Placeholder

影片特別強調：

Placeholder 的效率較低。

原因：

使用者開始輸入後：

```
Customer Number
```

會消失。

如果忘記：

> 這欄到底要填什麼？

就必須重新思考。

因此：

**Label 應永久存在。**

---

## 8. 說明文字放 Label 附近

例如：

```
Customer Number
（可於發票右上角找到）

[____________]
```

而不是：

```
[Customer Number]
```

這對：

* 認知障礙者
* 一般使用者

都更容易理解。

---

# 常見錯誤

❌ 只有 Placeholder，沒有 Label

❌ 色彩對比不足

❌ 錯誤訊息模糊

❌ 只能滑鼠操作

❌ Label 沒有綁定 Input

❌ Checkbox 點擊區域太小

---

# 推薦參考

講師推薦參考 **World Wide Web Consortium (W3C)** 的 **WCAG（Web Content Accessibility Guidelines）**，內容包含完整的網頁無障礙設計原則、範例與最佳實務，是學習 Accessibility 的重要資源。

---

# UI / UX 設計 Checklist

設計表單時，可快速檢查：

* ✅ 每個 Input 都有 Label
* ✅ Label 與 Input 正確關聯
* ✅ 支援鍵盤操作
* ✅ 色彩對比足夠
* ✅ 錯誤訊息清楚且即時
* ✅ Label 不依賴 Placeholder
* ✅ 提供必要的說明文字
* ✅ 表單欄位有合理分組
* ✅ 可供螢幕閱讀器辨識
* ✅ 大部分控制項具有足夠的點擊區域

---

## 核心觀念（一句話）

> **無障礙表單不是只為身心障礙者設計，而是讓所有使用者都能更快速、更容易、更順利地完成表單。**
