### 搜尋功能設計重點

#### 1. 搜尋框要容易被發現 (Visibility)

* 搜尋是內容型網站的重要功能時，應放在明顯的位置。
* 使用者應能第一眼找到搜尋入口，降低尋找成本。

#### 2. 一定要搭配放大鏡圖示 (Search Icon)

* 放大鏡是全球普遍認知的「搜尋」圖示。
* 即使沒有文字說明，大多數使用者也能立即理解用途。
* 建議放在搜尋框左側或搜尋按鈕上。

#### 3. 提供搜尋按鈕 (Search Button)

* 雖然 Enter 可以送出搜尋，但仍應提供可點擊的搜尋按鈕。
* 原因：

  * 符合部分使用者的操作習慣。
  * 明確告知「輸入後還需要執行搜尋」這個動作。
  * 提升整體可用性。

#### 4. 搜尋框大小要適當 (Input Size)

* 不要把搜尋框做得太短。
* 過短的輸入框會：

  * 無法完整看到查詢內容。
  * 不易修改文字。
  * 讓使用者傾向輸入較短、不精確的關鍵字。

**建議**

* 搜尋框可容納約 **27 個字元**。
* 約可滿足 **90%** 的搜尋查詢需求。

#### 5. 空間不足可使用展開式搜尋框 (Expandable Search)

* 若版面有限，可使用展開式搜尋框。
* 平時維持較小尺寸。
* 滑鼠懸停或點擊後再展開。
* 能兼顧：

  * 節省版面
  * 保持搜尋入口明顯
  * 提供足夠的輸入空間

---

## 搜尋框設計 Checklist

* ✅ 搜尋框放在容易發現的位置。
* ✅ 使用放大鏡圖示。
* ✅ 提供搜尋按鈕，不只支援 Enter。
* ✅ 輸入框至少可顯示約 **27 個字元**。
* ✅ 空間不足時，可採用展開式搜尋框。

---

### 核心原則

> **搜尋功能是網站中最常使用的介面之一，因此應優先考慮「容易發現、容易理解、容易操作」三大原則，而不是只追求節省版面。**
