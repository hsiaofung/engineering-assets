# 後續步驟（Next Steps）重點整理

## 表單是使用者與產品的核心互動

網頁表單不只是收集資料的工具，而是：

* 與使用者溝通的入口
* 協助使用者完成目標的工具
* 建立信任與關係的機會

好的表單可以：

* 降低使用者阻力
* 提升完成率（Conversion）
* 增加使用者信任

---

# 優秀表單 vs 糟糕表單差異

差異往往不是大型功能，而是細節：

* 按鈕顏色
* Label 位置
* 輸入格式
* 欄位數量
* 表單位置
* 錯誤提示方式

每個細節都可能影響使用者是否完成。

---

# 表單設計核心原則

---

# 1. 內容要相關（Relevant）

使用者剛閱讀的內容：

↓

應該與表單要求：

↓

有明確關聯。

例如：

使用者看到：

> 詢問房屋估價

表單應該問：

* 房屋地址
* 聯絡方式

而不是：

* 興趣
* 職業
* 不相關問題

---

# 2. 保持簡潔（Concise）

使用者沒有時間閱讀大量文字。

好的表單：

* 文案簡短
* 指示清楚
* 直接說明

避免：

❌

> 為了提供更好的服務品質與未來改善方向，我們需要您提供以下相關資訊...

---

較好：

✅

> 請填寫以下資訊，我們將於 24 小時內聯絡您。

---

# 3. 只詢問必要資料（Ask Only What Matters）

每增加一個欄位：

* 增加填寫成本
* 增加放棄機率

問自己：

> 這個資訊真的需要嗎？

例如：

註冊帳號：

需要：

✅ Email
✅ Password

可能不需要：

❌ 公司名稱
❌ 生日
❌ 地址

---

# 4. 分組與簡化（Group & Simplify）

長表單應分群：

例如：

## 個人資訊

* 姓名
* Email
* 電話

## 地址資訊

* 地址
* 城市
* 郵遞區號

---

不要：

```text
姓名
信用卡
電話
地址
Email
生日
```

全部混在一起。

---

# 5. 使用適當輸入控制項

不要讓使用者輸入可以選擇的資料。

例如：

❌

```text
請輸入國家：
____________
```

---

✅

Dropdown：

```text
國家：
[ Taiwan ▼ ]
```

---

## Checkbox 優於文字輸入

例如：

興趣：

❌

```text
請輸入興趣
____________
```

---

✅

```
☐ Design
☐ Programming
☐ Marketing
```

降低輸入成本。

---

# 6. 使用正確欄位類型

選擇正確 HTML Input：

| 資料    | Input             |
| ----- | ----------------- |
| Email | `type="email"`    |
| 電話    | `type="tel"`      |
| 日期    | `type="date"`     |
| 數字    | `type="number"`   |
| 密碼    | `type="password"` |

好處：

* 手機鍵盤最佳化
* 瀏覽器驗證
* 減少輸入錯誤

---

# 7. 即時驗證（Validate While Typing）

不要等：

填完整份表單 →

送出 →

才告訴錯誤。

更好的流程：

輸入中：

```
Password

✓ 8 characters
✓ Uppercase
✓ Number
❌ Symbol missing
```

使用者立即知道：

> 我是否做對。

---

# 8. 建立信任（Build Trust）

表單錯誤會造成：

* 挫折
* 放棄
* 不信任

因此：

表單應：

* 穩定
* 清楚
* 沒有錯誤
* 有良好回饋

---

# 9. 設計一致且美觀

表單應符合產品設計：

包含：

* 顏色
* 字型
* 間距
* 元件風格

不要：

網站：

現代 SaaS Design

表單：

1990 年代風格

---

# 10. 使用智慧欄位（Smart Fields）

智慧欄位可以降低使用者負擔。

例如：

輸入：

```
郵遞區號：
220
```

自動帶出：

```
城市：
新北市

區域：
板橋區
```

優點：

* 減少輸入
* 降低錯誤
* 加快完成速度

---

# 11. 對資料用途保持透明（Be Transparent）

使用者常會想：

> 為什麼需要我的資料？

應說明：

例如：

電話：

❌

```
Phone Number
```

---

✅

```
Phone Number
（方便客服與您確認訂單）
```

---

# 表單設計完整流程

```text
使用者需求
    ↓
清楚目的
    ↓
只收集必要資料
    ↓
適當欄位設計
    ↓
即時驗證
    ↓
清楚錯誤訊息
    ↓
成功回饋
    ↓
下一步指引
```

# Accessibility（無障礙）與 Usability（可用性）

影片最後再次區分：

## Accessibility（無障礙）

關心：

> 不同能力、背景的人是否能完成表單？

例如：

* 視障
* 使用鍵盤
* 使用 Screen Reader

---

## Usability（可用性）

關心：

> 一般使用者是否容易完成目標？

例如：

* 是否快速
* 是否容易理解
* 是否少犯錯

---

兩者關係：

```
Accessibility
      +
Usability
      ↓
Better User Experience
```

# 表單 UX Checklist

## 內容

* ✅ 表單目的清楚
* ✅ 只詢問必要資訊
* ✅ 文案簡潔
* ✅ 說明資料用途

---

## 結構

* ✅ 欄位合理分組
* ✅ 使用正確 Input Type
* ✅ 選項使用 Checkbox / Select
* ✅ 避免過長表單

---

## 互動

* ✅ 即時驗證
* ✅ 清楚錯誤訊息
* ✅ 成功後提供回饋
* ✅ 提供下一步

---

## 設計

* ✅ 符合品牌風格
* ✅ Desktop / Mobile 都好用
* ✅ 支援無障礙
* ✅ 減少使用者輸入成本

---

# 核心觀念（一句話）

> **好的表單不是要求使用者提供資料，而是設計一條讓使用者輕鬆完成目標的路徑；越理解使用者，就越能設計出高完成率、高信任度的表單。**
